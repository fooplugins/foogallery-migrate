## Security assessment and changes

The bounded independent review in the initial [release-prep report](1.16.1-test-results.md)
confirmed low-severity hardening/compliance issues. It did **not** establish SQL
injection or an exploitable low-privilege XSS path in its sampled findings. It also
did not audit every remaining query wrapper, exception sink or entry point.

- Added the missing ABSPATH guard in the WordPress Core gallery source. Direct
  execution now exits before class loading, preventing the prior class-not-found
  fatal and conditional error-path disclosure. Normal WordPress loading remains.
- Escaped the six literal translated `wp_die` messages in storage admin/cleanup,
  after translation and at the HTML output boundary. Permission checks and cleanup
  ownership/refusal behavior are unchanged. Internal error/exception payloads were
  not indiscriminately HTML-escaped.
- Replaced the variable translation call in preflight's error helper with literal
  translations at its callers. All seven messages are extractable; error codes and
  storage admission decisions stay unchanged.
- Corrected four text domains, six multi-placeholder messages and all 22 reported
  translator-comment omissions. English formatted output remains the same;
  translators can safely reorder numbered placeholders. Regenerated the POT.
- Sorted ZIP inputs using normalized relative paths and a locale-independent
  comparison; normalized ZIP timestamps to 1980-01-01. Repeated `gulp zip` builds
  from the frozen payload are byte-identical, independent of checkout file times.
  The translation-generation step still refreshes the tracked POT creation date;
  reproduce a release ZIP from the same frozen source/POT, not a newly dated POT.

No SQL, schema, ownership, nonce, capacity, storage-mode or migration-engine logic
was changed. Reviewed dynamic-IN placeholder and allocator-probe findings were
not rewritten merely to suppress them. Broad prefix/global-variable renaming,
generic SQL-wrapper changes and existing mixed line endings remain outside this
bounded repair; those findings still require specific review/disposition.
